Este tema incluye la integración [@astrojs/mdx](https://docs.astro.build/es/guides/integrations-guide/mdx/) instalada y configurada en tu archivo `astro.config.mjs`. Si prefieres no usar MDX, puedes desactivar el soporte eliminando la integración de tu archivo de configuración.

## ¿Por qué MDX?

MDX es una variante especial de Markdown que admite sintaxis JavaScript y JSX incrustada. Esto permite [mezclar JavaScript y componentes de UI dentro de tu contenido Markdown](https://docs.astro.build/es/guides/integrations-guide/mdx/#mdx-in-astro) para cosas como gráficas interactivas o alertas.

Si ya tienes contenido escrito en MDX, esta integración hará que migrar a Astro sea muy sencillo.

## Ejemplo

Así es como se importa y se usa un componente de UI dentro de MDX.  
Cuando abras esta página en el navegador, deberías ver el botón interactivo de abajo.

import HeaderLink from '@/components/HeaderLink.astro';

<HeaderLink href="#" onclick="alert('¡clic!')">
	Componente incrustado en MDX
</HeaderLink>
