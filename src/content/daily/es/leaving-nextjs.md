---
title: "Leaving Next.js"
excerpt: "Dejando Next.js y migrando este sitio a Astro y a mi propio servidor."
publishedDate: 2026-08-24
---

El día de hoy migré esta página web de Next.js a Astro y, de paso, dejé de alojarla en Vercel para comenzar a servirla desde mi propio servidor.

La decisión no surgió de algún problema en particular con Next.js o Vercel, sino más bien de una cuestión de principios.

Creo que muchas de las soluciones que construimos para la web no necesitan necesariamente un framework o meta framework para funcionar bien, en muchos casos, las tecnologías nativas de la web son más que suficientes, y herramientas como Astro permiten aprovecharlas manteniendo JavaScript y los frameworks únicamente en aquellos lugares donde realmente aportan valor.

Para este sitio quería algo más simple, con menos abstracciones y con mayor control sobre cómo se construye y se sirve.

El proyecto es open source y pueden encontrar todo el código [aquí](https://github.com/oscar-castaneda-dev/oscar-castaneda).

El proyecto original construido con Next.js también seguirá siendo público [aquí](https://github.com/oscar-castaneda-dev/oscar-castaneda-website), por si alguien quiere consultarlo o utilizarlo como referencia.

Next.js sigue siendo una gran opción para muchos proyectos, simplemente, para este, ya no lo necesito.
