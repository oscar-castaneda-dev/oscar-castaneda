---
title: "Confundimos mejorar la experiencia del desarrollador con mejorar la web"
excerpt: "Quizá llevamos años creando soluciones para problemas que la web ya había resuelto."
publishedDate: 2026-08-25
---

Estaba leyendo la [documentación de HTMX](https://htmx.org/) y me hizo pensar en cuántas abstracciones hemos creado para hacer más sencillo desarrollar para la web: frameworks, reactividad, compiladores y nuevas formas de construir interfaces, y durante el proceso, quizá, olvidamos que muchos de esos problemas ya tenían solución: HTML, links, forms, GET y POST.

Tal vez React no fue una mala solución, tal vez el problema fue convertir este tipo de abstracciones en el punto de partida, incluso cuando las herramientas de la web ya eran suficientes, eso es lo que me gusta de HTMX, nos recuerda cuánto podemos hacer simplemente usando la web como fue diseñada.
